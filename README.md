# Mitch’s Handyman Services — unofficial concept

Unpublished, local one-page mockup. No deploy has been created. The Netlify project is intentionally empty and not connected to Git continuous deployment. The build command blocks publishing. `.netlify/` is ignored.

Run `./preview.command`, or serve `public/` locally with Python. The site also works by opening `public/index.html` directly.

Business name, Syosset location, phone, email, and the original four services were user-supplied and corroborated on the matching Nextdoor profile. Minor electrical and plumbing repairs and backyard projects were added from the business-authored “Our story” section. See SOURCES.md. No street address, hours, prices, credentials, or service-area boundaries are asserted. No form, analytics, or remote fonts are included.
